# Study Notes
Organizing some study notes for my personal interests. I am digitizing these from my handwritten notes periodically, or else converting them from code I have written, and managing them using Obsidian.

## Workflow
I will keep a weekly summary note (not synced) in addition to notes per-topic/per-exercise/per-section as necessary. There will be some cross-linking between files, but it likely will not work directly on GitHub. I keep pictures of my handwritten notes as attachments locally, but they are not synced.
