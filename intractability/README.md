# Computational Intractability: A Guide to Algorithmic Lower Bounds
This is the text published by Demaine, Gasarch, and Hajiaghayi in 2026. I picked it up because I enjoyed Gasarch's undergrad class at UMD.

Since this is very recently published, I am completing the exercises at my own discretion. I will note that the publishing timeline for this text was unfortunate because a counterexample for ETH was provided just days after its release.

Each chapter is organized into its own subfolder with one notes file and an additional subfolder for exercises.
